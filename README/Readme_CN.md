# Body Slider Pro - 用户说明书

> **Crimson Desert** 体型与模型调节工具。  
> 简单易用，也适合进阶 MOD 制作。

---

## 这是什么？

Body Slider Pro 是一款为 **Crimson Desert** 模型提供"滑块调节"的工具。

虽然名字里有"Body（体型）"，但它其实可以为游戏中**任意模型**创建滑块：
- 角色体型
- 脸型
- 服装
- 怪物
- 道具物品

只要你能找到对应的 `.pac` 文件，就可以用本工具为其创建变形滑块。

这意味着：
- **普通玩家**：可以直接使用内置滑块，自由调节体型。
- **进阶用户**：可以导入其他 MOD 的 `.pac` 文件，基于别人的模型创建滑块。
- **MOD 作者**：可以用建模软件修改模型，再导入本工具生成自定义滑块。

---

## 工作原理（简要）

1. 工具从 `.pac` 文件中解包出游戏的原始模型，称为 **原始网格（Original Mesh）**。
2. 你在不改变拓扑结构和 UV 的前提下编辑模型，编辑后的模型称为 **目标网格（Target Mesh）**。
3. 因为拓扑未变，Body Slider Pro 可以在"原始网格"和"目标网格"之间构建顶点变形器，从而生成滑块。
4. 因为 UV 未变，所以不需要修改贴图。

简单理解：
- 原始网格 = 基础模型
- 目标网格 = 修改后的模型（结构相同）
- 滑块 = 在两者之间平滑过渡

## 界面概览

打开 Body Slider Pro 后，你会看到：

- **左侧面板**：3D 模型预览窗口。
- **右侧面板**：角色标签页、滑块列表与操作按钮。
- **最右侧**（可选）：服装面板，当当前角色有服装数据时显示。
- **顶部栏**：语言选择、角色标签页、角色操作与全局按钮。

### 主要按钮说明

| 按钮 | 说明 |
|---|---|
| **＋ 添加角色** | 添加一个新角色进行管理。 |
| **⇋ 排序角色** | 拖拽调整角色标签页的顺序。 |
| **编辑属性**（每个角色） | 修改该角色的名称、ID、原始 PAC、Mod 路径。 |
| **× 删除角色**（每个角色） | 删除该角色及其相关文件。 |
| **重置数值** | 将当前角色的所有滑块值恢复为 0。 |
| **重置全部** | 将所有角色的设置和滑块恢复为默认值。 |
| **+ 添加自定义滑块** | 使用目标网格创建新的自定义滑块。 |
| **导出模型 (.obj)** | 将当前模型导出为 `.obj`，用于在建模软件中编辑。 |
| **导出为 MOD 文件夹** | 将当前滑块配置打包为可直接使用的 MOD。 |
| **重置视角** | 将 3D 视角恢复为默认。 |
| **线框** | 开关模型线框显示。 |
| **▶/◀ 展开/收起服装面板** | 切换右侧服装面板的显示（仅在有服装数据时出现）。 |
| **卸载所有服装** | 删除当前角色的所有服装数据。 |
| **保存/分享角色包** | 将当前角色配置与滑块导出为 `.zip` 包，方便备份或分享。 |
| **读取角色包** | 导入自己或他人分享的角色包（可包含服装数据）。 |

## 快速上手（普通玩家）

你只想调整自己的体型，不需要任何 MOD 知识。

### 第一步：选择角色

- 在顶部使用角色标签页切换角色。
- 默认角色（如 **Damiane**）已配置好，可直接使用。

### 第二步：调节滑块

- 在 **默认滑块** 中拖动滑块，自由调节体型。
- 左侧 3D 窗口会实时预览效果。

### 第三步：使用其他 MOD 的体型（可选）

如果你喜欢某个 MOD 的体型，想通过滑块调节它：

1. 从该 MOD 中找到对应角色的 `.pac` 文件（例如 Damiane 通常为 `cd_phw_00_nude_00_0001_damian.pac`）。
   - 注意：该 `.pac` 必须与当前角色的原始 PAC 是**同一个角色/物品**。
2. 在 Body Slider Pro 中：
    - 点击 **+ 添加自定义滑块**。
    - 输入滑块名称。
    - 在 **目标网格** 中选择该 `.pac` 文件。
 3. 拖动新滑块，可以在默认体型与该 MOD 体型之间调节。
 4. 点击 **导出为 MOD 文件夹**。
5. 将 `/exported_mod/` 下的文件夹复制到你的 Mod Manager 管理 MOD 的位置，启用即可。

完成。

## 服装系统

Body Slider Pro 支持为角色加载和管理服装。服装数据通过 **角色包** 导入，加载后服装会跟随体型滑块同步变形。

### 如何获取服装

服装数据由 MOD 作者打包在角色包（`.zip`）中提供。只需用 **读取角色包** 功能导入包含服装数据的角色包即可。

### 如何使用服装

1. 导入包含服装数据的角色包后，界面右侧会出现 **▶/◀ 按钮**。
2. 点击 **▶/◀** 按钮展开 **服装面板**，面板中以文件树形式展示可用的服装文件（`.pac` / `.obj`）。
3. **点击** 某个服装文件即可 **激活** 该服装，服装会出现在 3D 预览窗口中，并跟随当前滑块值同步变形。
4. **再次点击** 已激活的服装文件可 **停用** 它。
5. 点击 **卸载所有服装** 可删除当前角色的所有服装数据。

### 注意事项

- 服装面板仅在当前角色有服装数据时显示。
- 激活的服装会跟随所有体型滑块实时变形。
- 导出 MOD 时，已配置的服装数据会一并打包。

## MOD 作者指南（用建模软件创建自定义滑块）

适用于想自己制作体型/脸型/服装等变形，并以滑块形式分享的用户。

### 第一步：准备原始 PAC

1. 使用 **Crimson Desert Mod Workbench** 等工具，解包你要修改的模型的 `.pac` 文件。
   - **重要：在整个流程中，请勿修改该原始 PAC 文件的文件名。**
2. 在 Body Slider Pro 中：
   - 点击 **＋ 添加角色**。
   - 填写：
     - **角色名称**：显示名称（如"我的自定义体型"）。
     - **角色 ID**：仅允许英文字母、数字、下划线（如 `my_body_01`）。
     - **原始 PAC**：选择刚才解包的 `.pac` 文件。
     - **Mod 路径**：相对于 `files` 文件夹的路径（如 `character\model\1_pc\2_phw\nude`）。

### 第二步：导出 OBJ

1. 在该角色的标签页中，点击 **导出模型 (.obj)**。
   - 建议：导出前将所有滑块归零，确保导出的 OBJ 与游戏原始模型一致。
2. 在建模软件（如 Blender）中打开导出的 `.obj` 文件。

### 第三步：编辑模型

编辑时：

- **不要**：
  - 改变顶点数量
  - 改变拓扑结构（布线）
  - 改变 UV 布局
- **可以**：
  - 移动顶点来修改形状

保持结构完全一致，只改变顶点位置。

**保持 UV 的实用方法（以 Blender 为例）：**

1. 编辑前先复制一份原始对象作为备份。
2. 为正在编辑的对象添加 **Data Transfer** 修改器。
3. 在 Data Transfer 中：
   - **Source（源）** 选择刚才复制的备份对象。
   - 勾选 **Face Corner Data** → 启用 **UVs**，Mapping 选择 **Topology**。
   - 勾选 **Face Data**，Mapping 选择 **Topology**。
4. 在编辑模式下修改模型，避免对 UV 做结构性改变（如重新排布岛、拆分面等）。
5. 提示：尽量不使用雕刻模式，除非你能确保 UV 布局不被破坏。

### 第四步：导出编辑后的模型

- 将编辑后的模型导出为 `.obj`。
- 确保：
  - 对象数量和名称与原 OBJ 一致。
  - 顶点数和结构相同。

### 第五步：创建自定义滑块

1. 在 Body Slider Pro 中，进入对应角色的标签页。
2. 点击 **＋ 添加自定义滑块**。
3. 填写：
   - **名称**：如"自定义胸部"。
   - **目标网格**：选择你编辑后的 `.obj` 文件。
   - **范围**：最小值,最大值（如 `-50,150`）。
4. 拖动滑块，确认变形效果正确。

### 第六步：打包或分享

你有两种选择：

- **导出为 MOD 文件夹**：
  - 在 `/exported_mod/` 中生成可直接使用的 MOD。
  - 复制到 Mod Manager 启用即可。

- **保存/分享角色包**：
  - 导出包含角色配置与滑块的 `.zip`（含目标网格文件）。
  - 他人可通过 **读取角色包** 导入使用。

注意：
- 如果你的目标网格基于其他作者的模型，在分享前请**取得授权**。

## 重要文件夹说明

| 文件夹 | 用途 |
|---|---|
| `original_mesh/` | 存放每个角色的原始网格（来自原始 PAC）。 |
| `target_mesh/` | 存放滑块使用的目标网格。 |
| `exported_mesh/` | 导出 OBJ 文件的目录。 |
| `exported_mod/` | 打包生成的 MOD 文件夹，可直接用于 Mod Manager。 |
| `char_config/` | 角色与滑块的配置文件（`.json`）。 |
| `original_outfit/` | 存放每个角色的原始服装数据（通过角色包导入）。 |
| `exported_outfit/` | 存放处理后（跟随滑块变形）的服装数据。 |
| `crash_report/` | 自动生成的崩溃日志，反馈 BUG 时请附上对应日志。 |

## 使用小贴士

- **精准预览**：使用 **线框** 和 **重置视角** 辅助观察模型。
- **恢复默认**：使用 **重置数值** 将所有滑块归零。
- **多角色管理**：可通过不同角色标签页管理不同体型或服装。
- **角色排序**：使用 **⇋ 排序角色** 拖拽调整角色标签页顺序。
- **备份与分享**：使用 **保存/分享角色包** 备份或分享你的配置（含服装数据）。
- **服装管理**：通过右侧服装面板快速切换和预览不同服装。
- **展开/收起服装**：使用 **▶/◀ 展开/收起服装面板** 切换服装面板显示。

## 反馈 BUG

如果 Body Slider Pro 出现崩溃或异常：

1. 打开 `crash_report/` 文件夹。
2. 按时间找到对应的错误日志。
3. 反馈 BUG 时，请附带该日志文件。

---

## 注意事项

- 滑块仅在"原始 PAC"与"目标网格"结构一致时生效（子网格数量、名称、顶点数必须相同）。
- 如果提示"网格不兼容"，请检查两者是否来自同一基础模型。

## 如何添加语言翻译

如果你想为 Body Slider Pro 添加新的语言翻译：

1. 在 `language/` 文件夹中复制一份现有语言文件，例如 `en.json`。
2. 将新文件命名为对应语言的代码，如 `ja.json`（日语）、`fr.json`（法语）等。
3. 用文本编辑器打开新文件：
   - 修改 `"lang_name"` 为该语言的显示名称（如 `"Japanese"`）。
   - 将所有值（右侧引号内的文本）翻译成目标语言。
   - 不要修改键名（左侧引号内的内容）、逗号或大括号。
4. 保存文件后，重新启动 Body Slider Pro，在顶部语言选择器中选择新语言。

如发现问题，可对照 `en.json` 检查是否遗漏或误改了键名。
