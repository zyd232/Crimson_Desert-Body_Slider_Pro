# Body Slider Pro - 사용자 설명서

> **Crimson Desert** 체형 및 모델 조정 도구.  
> 간단하고 직관적이며, 모더를 위한 강력한 기능 제공.

---

## Body Slider Pro란?

Body Slider Pro는 **Crimson Desert**의 모델을 슬라이더로 조정하는 도구입니다.

이름에 "Body(체형)"이 포함되어 있지만, 게임 내 **모든 모델**에 슬라이더를 만들 수 있습니다:
- 캐릭터 체형
- 얼굴 형태
- 의상
- 몬스터
- 소품 및 아이템

해당 모델의 `.pac` 파일만 찾을 수 있다면 슬라이더를 만들 수 있습니다.

즉:
- **일반 사용자**: 내장된 슬라이더로 체형을 자유롭게 조정할 수 있습니다.
- **고급 사용자**: 다른 MOD의 `.pac` 파일을 가져와 슬라이더를 만들 수 있습니다.
- **모더**: 3D 소프트웨어로 모델을 수정한 후 이 도구에서 커스텀 슬라이더를 생성할 수 있습니다.

---

## 작동 원리 (간략)

1. 도구에서 `.pac` 파일을 해제하여 게임의 원본 모델을 추출합니다. 이를 **원본 메쉬(Original Mesh)**라고 합니다.
2. 위상 구조와 UV를 바꾸지 않고 모델을 수정하면, 이를 **목표 메쉬(Target Mesh)**라고 합니다.
3. 위상 구조가 동일하므로, Body Slider Pro는 원본 메쉬와 목표 메쉬 사이에 정점 변형기(Vertex Deformer)를 만들어 슬라이더를 생성합니다.
4. UV가 동일하므로 텍스처 수정은 필요 없습니다.

간단히 말하면:
- 원본 메쉬 = 기본 모델
- 목표 메쉬 = 수정된 모델 (구조 동일)
- 슬라이더 = 두 모델 사이를 부드럽게 전환

---

## 인터페이스 개요

Body Slider Pro를 실행하면:

- **왼쪽 패널**: 3D 모델 미리보기.
- **오른쪽 패널**: 캐릭터 탭, 슬라이더 목록, 조작 버튼.
- **가장 오른쪽** (선택적): 의상 패널 영역, 의상 파일 트리, 의상 기본 슬라이더, 의상 커스텀 슬라이더 세 패널을 포함.
- **상단 바**: 언어 선택, 캐릭터 탭, 캐릭터 관리, 전체 버튼.

### 주요 버튼

| 버튼 | 설명 |
|---|---|
| **+ 캐릭터 추가** | 관리할 새 캐릭터 추가. |
| **⇋ 캐릭터 정렬** | 캐릭터 탭 순서를 드래그하여 재정렬. |
| **속성 편집** (캐릭터별) | 해당 캐릭터의 이름, ID, 원본 PAC, MOD 경로 수정. |
| **× 삭제** (캐릭터별) | 캐릭터 및 관련 파일 삭제. |
| **초기화** | 현재 캐릭터의 모든 슬라이더 값을 0으로 초기화. |
| **모두 초기화** | 모든 캐릭터 설정 및 슬라이더를 기본값으로 초기화. |
| **+ 커스텀 슬라이더 추가** | 목표 메쉬를 사용하여 새로운 슬라이더 생성. |
| **모델 내보내기 (.obj)** | 현재 모델을 `.obj`로 내보내 3D 소프트웨어에서 편집. |
| **MOD 폴더로 내보내기** | 현재 슬라이더 설정을 즉시 사용 가능한 MOD로 패키징. |
| **카메라 초기화** | 3D 뷰를 기본값으로 되돌림. |
| **와이어프레임** | 모델의 와이어프레임 표시 토글. |
| **▶/◀ 의상 패널 표시/숨기기** | 오른쪽 의상 패널 영역 토글 (의상 데이터가 있을 때만 표시). |
| **모든 의상 제거** | 현재 캐릭터의 모든 의상 데이터 삭제. |
| **+ 의상 커스텀 슬라이더 추가** | 현재 활성화된 의상에 대한 독립 커스텀 슬라이더 생성. |
| **의상 모델 내보내기 (.obj)** | 현재 활성화된 의상을 `.obj` 파일로 내보내기. |
| **캐릭터 팩 저장/공유** | 캐릭터 설정과 슬라이더를 `.zip` 팩으로 내보내 백업 또는 공유. |
| **캐릭터 팩 불러오기** | 자신이나 다른 사용자가 공유한 캐릭터 팩 가져오기 (의상 데이터 포함 가능). |

## 빠른 시작 (일반 사용자)

체형을 조정하고 싶지만 MOD 지식이 필요 없어도 됩니다.

### 1단계: 캐릭터 선택

- 상단의 캐릭터 탭에서 캐릭터를 선택합니다.
- 기본 캐릭터(예: **Damiane**)는 이미 설정되어 있어 바로 사용할 수 있습니다.

### 2단계: 슬라이더 조정

- **기본 슬라이더**에서 슬라이더를 드래그하여 체형을 자유롭게 조정.
- 왼쪽 3D 뷰에서 실시간으로 미리보기.

### 3단계: 다른 MOD의 체형 사용 (선택 사항)

다른 모더의 체형을 슬라이더로 조정하고 싶다면:

1. 해당 MOD에서 캐릭터의 `.pac` 파일을 찾습니다. (예: Damiane의 경우 보통 `cd_phw_00_nude_00_0001_damian.pac`)
   - 중요: 이 `.pac`는 현재 캐릭터의 원본 PAC과 **동일한 캐릭터/아이템**이어야 합니다.
2. Body Slider Pro에서:
    - **+ 커스텀 슬라이더 추가** 클릭.
    - 슬라이더 이름 입력.
    - **목표 메쉬**에서 해당 `.pac` 파일 선택.
3. 새 슬라이더를 드래그하여 기본 체형과 MOD 체형 사이를 조정.
4. **MOD 폴더로 내보내기** 클릭.
5. `/exported_mod/` 폴더에서 생성된 MOD 폴더를 Mod Manager의 MOD 디렉토리로 복사 후 활성화.

완료.

## 의상 시스템

Body Slider Pro는 캐릭터에게 의상을 로드하고 관리하는 기능을 지원합니다. 의상 데이터는 **캐릭터 팩 불러오기** 기능을 통해 가져오며, 로드된 의상은 체형 슬라이더와 동기화되어 변형됩니다.

오른쪽에는 세 가지 의상 관련 패널이 표시됩니다 (왼쪽부터 오른쪽으로):
- **의상 패널**: 사용 가능한 의상 파일(`.pac` / `.obj`)을 파일 트리 형태로 표시.
- **의상 기본 슬라이더 패널**: 캐릭터 기본 슬라이더에 해당하는 의상 변형 슬라이더.
- **의상 커스텀 슬라이더 패널**: 캐릭터 커스텀 슬라이더 + 독립 의상 커스텀 슬라이더의 변형 제어.

### 의상 얻기

의상 데이터는 MOD 작성자가 캐릭터 팩(`.zip`)에 담아 제공합니다. **캐릭터 팩 불러오기** 기능을 사용하여 의상 데이터가 포함된 캐릭터 팩을 가져오면 됩니다.

가져올 때 동일한 ID를 가진 캐릭터가 이미 존재하고 의상 데이터가 있는 경우, 다음 중 하나를 선택하라는 메시지가 표시됩니다:
- **덮어쓰기**: 기존 의상 데이터를 모두 가져온 데이터로 대체.
- **병합**: 의상 데이터를 병합하고 중복 파일은 하나씩 충돌 해결.

### 의상 사용 방법

1. 의상 데이터가 포함된 캐릭터 팩을 가져오면, 인터페이스 오른쪽에 **▶/◀ 버튼**이 표시됩니다.
2. 버튼을 클릭하면 의상 패널 영역이 확장되며, 의상 파일 트리와 슬라이더 패널이 표시됩니다.
3. 의상 파일을 **클릭**하면 해당 의상이 **활성화**됩니다. 의상이 3D 미리보기에 표시되며(주황색), 현재 슬라이더 값과 동기화되어 변형됩니다.
4. 활성화된 의상을 **다시 클릭**하면 **비활성화**됩니다.
5. **모든 의상 제거**를 클릭하면 현재 캐릭터의 모든 의상 데이터가 삭제됩니다 (`original_outfit/{char_id}` 및 `exported_outfit/{char_id}` 디렉토리 포함).

### 의상 파일 트리 조작

의상 파일 트리에 다음 도구 모음 버튼이 제공됩니다:
- **모두 확장 / 모두 접기**: 모든 폴더를 빠르게 확장 또는 접기.
- **새로고침**: 디스크에서 의상 파일을 다시 스캔.
- **모두 선택 / 모두 선택 해제**: 모든 의상 파일의 체크박스를 일괄 선택 또는 해제 (체크박스는 활성화 상태를 나타내지 않음).

### 의상 슬라이더 시스템

의상을 활성화하면 오른쪽에 **의상 기본 슬라이더**와 **의상 커스텀 슬라이더** 두 패널이 나타나며, 의상이 체형 변화와 얼마나 함께 변형될지 제어할 수 있습니다.

#### 의상 기본 슬라이더

캐릭터 기본 슬라이더(가슴 크기, 허리, 엉덩이 등)와 일대일 대응합니다. 각 슬라이더는 기본적으로 캐릭터 슬라이더와 **연결**(동기화)되어 있으며, 캐릭터 슬라이더를 드래그하면 의상 슬라이더가 자동으로 따라갑니다.

#### 의상 커스텀 슬라이더

두 가지 유형을 포함합니다:
1. **캐릭터 커스텀 슬라이더에 해당하는 의상 슬라이더** — 캐릭터 패널에서 생성한 커스텀 슬라이더에 대응.
2. **독립 의상 커스텀 슬라이더** — 의상 전용 슬라이더로, 캐릭터 슬라이더에 의존하지 않음 (아래 참조).

#### 연결 / 연결 해제

각 의상 슬라이더 왼쪽에 **연결 버튼**이 있습니다:
- **🔗 (연결됨)**: 의상 슬라이더 값이 해당 캐릭터 슬라이더와 동기화됩니다. 캐릭터 슬라이더를 드래그하면 의상이 자동으로 변형됩니다.
- **⛓️‍💥 (연결 끊김)**: 의상 슬라이더 값이 캐릭터 슬라이더와 독립적이므로, 캐릭터 체형에 영향을 주지 않고 의상 변형 정도를 별도로 조정할 수 있습니다.

버튼을 클릭하여 두 상태 간 전환. 연결이 끊기면 슬라이더 값이 `outfit_config/` 디렉토리에 저장되며, 다음 실행 시 복원됩니다.

각 슬라이더에는 해당 슬라이더 값을 0으로 되돌리는 **초기화(Reset)** 버튼도 있습니다.

### 독립 의상 커스텀 슬라이더

캐릭터 슬라이더를 따르는 것 외에도, 현재 활성화된 의상에 대해 **별도 커스텀 슬라이더를 생성**하여 캐릭터 체형에는 영향을 주지 않고 의상에만 영향을 미치는 특수 변형 효과를 만들 수 있습니다.

#### 독립 의상 커스텀 슬라이더 추가

1. 의상이 활성화되어 있는지 확인.
2. **"+ 의상 커스텀 슬라이더 추가"** 버튼 클릭.
3. 슬라이더 이름과 ID 입력 (영문자, 숫자, 언더스코어만 가능).
4. 목표 메쉬 파일 선택 (`.obj` 또는 `.pac`) — 수정한 의상 모델입니다.
5. 범위 설정 (예: `-50,150`).

생성된 슬라이더는 **의상 커스텀 슬라이더** 패널에 나타나며 연결 버튼은 표시되지 않습니다 (독립적이기 때문).

#### 편집 및 삭제

각 독립 의상 커스텀 슬라이더에 다음 버튼이 있습니다:
- **편집** 버튼: 슬라이더 이름, ID 수정 또는 목표 메쉬 파일 교체.
- **× (삭제)** 버튼: 이 슬라이더와 관련 데이터 모두 삭제.

#### 주의사항

- 독립 의상 커스텀 슬라이더의 목표 메쉬 파일은 `exported_outfit/{char_id}/custom/{slider_id}/` 디렉토리에 배포됩니다.
- 슬라이더 ID는 동일한 캐릭터 내에서 고유해야 합니다.
- 모델을 편집할 때는 원본 의상과 정점 수와 위상 구조를 동일하게 유지해야 합니다.

### 의상 모델 내보내기

**"의상 모델 내보내기 (.obj)"** 버튼을 클릭하면 현재 활성화된 의상을 `.obj` 파일로 내보낼 수 있으며, Blender 등 3D 모델링 소프트웨어에서 편집할 수 있습니다. 편집한 모델은 독립 의상 커스텀 슬라이더 생성에 사용할 수 있습니다.

### 주의사항

- 의상 패널은 현재 캐릭터에 의상 데이터가 있을 때만 표시됩니다.
- 활성화된 의상은 모든 체형 슬라이더와 실시간으로 변형됩니다.
- MOD를 내보낼 때 설정된 의상 데이터도 함께 패키징됩니다.
- 캐릭터에 의상 데이터가 있는 경우 일부 작업(캐릭터 삭제 등)이 제한됩니다. 이러한 작업을 수행하기 전에 먼저 **모든 의상 제거**를 실행하세요.

## 모더를 위한 가이드 (3D 소프트웨어로 커스텀 슬라이더 만들기)

체형/얼굴/의상 등을 직접 만들어 슬라이더로 공유하려는 사용자를 위한 워크플로우입니다.

### 1단계: 원본 PAC 준비

1. **Crimson Desert Mod Workbench** 등의 도구로 수정할 모델의 `.pac` 파일을 해제.
   - **중요: 전체 작업 과정에서 이 원본 PAC 파일의 파일명은 변경하지 마세요.**
2. Body Slider Pro에서:
    - **+ 캐릭터 추가** 클릭.
    - 다음 항목 입력:
      - **캐릭터 이름**: 표시 이름 (예: "내 커스텀 체형").
      - **캐릭터 ID**: 영문자, 숫자, 언더스코어만 가능 (예: `my_body_01`).
      - **원본 PAC**: 방금 해제한 `.pac` 파일 선택.
      - **MOD 경로**: `files` 폴더 기준 상대 경로 (예: `character\model\1_pc\2_phw\nude`).

### 2단계: OBJ 내보내기

1. 해당 캐릭터 탭에서 **모델 내보내기 (.obj)** 클릭.
    - 팁: 내보내기 전에 모든 슬라이더를 0으로 초기화하여 원본 모델과 동일한 OBJ를 확보.
2. 3D 모델링 소프트웨어(Blender 등)에서 내보낸 `.obj` 파일 열기.

### 3단계: 모델 편집

편집 시:

- **하지 말 것**:
  - 정점 수 변경
  - 위상 구조(에지 흐름) 변경
  - UV 레이아웃 변경
- **할 수 있는 것**:
  - 정점을 이동하여 모양 수정

구조는 그대로 유지하고 위치만 변경.

**UV 유지 권장 워크플로우 (Blender 예시):**

1. 편집 전 원본 객체를 복사하여 백업.
2. 편집할 객체에 **Data Transfer** 수정기 추가.
3. Data Transfer 설정:
    - **Source(소스)**: 방금 복사한 백업 객체 선택.
    - **Face Corner Data** 체크 → **UVs** 활성화, Mapping: **Topology**.
    - **Face Data** 체크, Mapping: **Topology**.
4. Edit Mode에서 모델 수정 시 UV의 구조적 변경(섬 재배치, 면 분할 등) 피하기.
5. 참고: UV 레이아웃이 손상되지 않을 수 있는 경우 외에는 Sculpt Mode는 피하는 것이 좋습니다.

### 4단계: 수정된 모델 내보내기

- 수정된 모델을 `.obj`로 내보내기.
- 다음을 확인:
  - 오브젝트 수와 이름이 원본 OBJ와 동일.
  - 정점 수와 구조가 동일.

### 5단계: 커스텀 슬라이더 생성

1. Body Slider Pro에서 해당 캐릭터 탭으로 이동.
2. **+ 커스텀 슬라이더 추가** 클릭.
3. 다음 항목 입력:
    - **이름**: 예: "커스텀 가슴".
    - **목표 메쉬**: 수정한 `.obj` 파일 선택.
    - **범위**: 최소,최대 (예: `-50,150`).
4. 슬라이더를 드래그하여 변형이 올바른지 확인.

### 6단계: 패키징 또는 공유

두 가지 옵션이 있습니다:

- **MOD 폴더로 내보내기**:
  - `/exported_mod/`에 즉시 사용 가능한 MOD를 생성.
  - Mod Manager에 복사 후 활성화.

- **캐릭터 팩 저장/공유**:
  - 캐릭터 설정과 슬라이더(목표 메쉬 포함)를 `.zip`으로 내보냄.
  - 다른 사용자가 **캐릭터 팩 불러오기**로 가져올 수 있음.

주의:
- 목표 메쉬가 다른 창작자의 작업을 기반으로 한다면, 공유 전에 **허락**을 받아야 합니다.

| 폴더 | 용도 |
|---|---|
| `original_mesh/` | 각 캐릭터의 원본 메쉬 (원본 PAC 기반). |

| `crash_report/` | 자동 생성되는 크래시 로그. 버그 신고 시 해당 로그 첨부. |

## 유용한 팁

- **정확한 미리보기**: **와이어프레임**과 **카메라 초기화**를 사용해 모델을 확인.
- **기본값 복원**: **초기화**로 모든 슬라이더를 0으로 되돌림.
- **다중 캐릭터 관리**: 각 캐릭터 탭으로 다른 체형 또는 의상을 관리.
- **캐릭터 정렬**: **⇋ 캐릭터 정렬**을 사용해 탭 순서를 드래그하여 재정렬.
- **백업 및 공유**: **캐릭터 팩 저장/공유**로 설정을 백업하거나 공유 (의상 데이터 포함).
- **의상 관리**: 오른쪽 의상 패널을 사용해 다른 의상을 빠르게 전환하고 미리보기.
- **의상 표시/숨기기**: **▶/◀ 의상 패널 표시/숨기기**를 사용해 의상 패널 영역 토글.
- **의상 독립 변형**: 의상 슬라이더의 캐릭터 슬라이더 연결을 끊으면 의상 변형 정도를 별도로 조정할 수 있습니다.
- **의상 커스텀 슬라이더**: 캐릭터 체형에 영향을 주지 않고 의상 전용 변형 효과를 만드세요.

## 버그 신고

Body Slider Pro에서 충돌 또는 이상 동작이 발생하면:

## 언어 번역 추가하기

Body Slider Pro에 새로운 언어를 추가하려면:

1. `language/` 폴더에서 기존 언어 파일(예: `en.json`)을 복사.
2. 새 파일을 대상 언어 코드로 이름 붙이기, 예: `ja.json`(일본어), `fr.json`(프랑스어).
3. 텍스트 편집기로 파일 열기:
    - `"lang_name"`을 해당 언어의 표시 이름으로 변경 (예: `"Japanese"`).
    - 모든 값(각 `:` 오른쪽의 텍스트)을 대상 언어로 번역.
    - 키(왼쪽 텍스트), 쉼표, 중괄호는 절대 변경 금지.
4. 저장 후 Body Slider Pro를 재시작하고 상단 언어 선택기에서 새 언어 선택.

문제가 발생하면 `en.json`과 비교하여 누락 또는 수정된 키가 있는지 확인.
